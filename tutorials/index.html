    Tutorials¶

    Each tutorial is a complete, runnable workflow for one task, at the benchmarks' settings.

    • Fitting an image

      FUTON and the baselines on a Kodak image, with learning curves.

      Needs an image.

    • Occupancy volumes

      A 3D shape as an INR on \([-1, 1]^3\), scored by IoU and exported as a mesh.

      Needs a mesh and the 3d extra.

    • Radiance fields

      Any model as the density network of a NeRF, trained on posed views and rendered in orbit.

      Needs a Blender scene.

    • Notebooks

      Three notebooks that run one signal end to end, with every plot.

      Needs the data.
